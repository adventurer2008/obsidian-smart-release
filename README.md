# 无界同步（Wujie Sync）国内版

面向中国用户的 Obsidian 同步插件。插件 ID：`wujie-sync`。本仓库提供国内版源码快照、安装包、使用说明及更新记录。[English](README.en.md)

**公测期内，请申请开通。** 当前为免费公测，使用托管同步服务需要账号及审核批准。未来收费及公测访问规则的变化会提前通知，目前未公布付费方案。

## 主要功能与亮点

### 多端同步

- **笔记与附件**：在设备间同步笔记、图片、音频、视频等附件，以及选定的 Obsidian 设置。
- **按需同步**：可设置同步方向、排除规则和附件下载偏好，控制哪些内容参与同步。
- **设备配对**：通过配对、指纹核对与确认授权添加设备，避免反复填写连接信息。
- **设备管理**：查看设备状态，撤销不再使用的设备授权。
- **保留原时间**：同步保留文件原始修改时间，避免下载时间替代原来的编辑时间。

### 加密贯穿同步流程

- **内容加密**：笔记正文、路径及原始修改时间使用 AES-256-GCM，在客户端加密后上传，云端保存密文。
- **传输保护**：上传和下载均通过 HTTPS/TLS，接收设备在本地校验、解密内容。
- **密钥派生**：使用 PBKDF2-SHA-256、随机盐及 31 万次迭代，从加密口令派生密钥，提高口令猜测成本。
- **安全配对**：新设备通过 ECDH 密钥协商和 AES-256-GCM 加密传递连接信息，并需核对指纹、确认授权。
- **密钥登录**：系统生成高随机性登录密钥，减少弱密码和重复密码问题，并支持设备授权与撤销。
- **权限与解密分离**：登录密钥用于访问服务，加密口令用于解密笔记；两者都需要妥善保管。
- **安全边界**：账号和部分运行信息不属于内容加密范围；加密不能替代设备安全与备份，目前未经过独立第三方安全审计。

### 高效同步

- **增量识别**：结合变更检测和指纹缓存，减少重复扫描与不必要的传输。
- **批量处理**：合批提交与下载，减少大量小文件产生的往返请求。
- **压缩与流式传输**：加密前尝试压缩，大文件按分片处理，降低传输量和内存占用。
- **局域网加速**：可选设备间认证密文传输，不可用时自动回退云端。
- **进度可查**：任务面板展示进度与记录，支持失败后补传；实际速度取决于文件、网络和设备。

### 插件与配置管理

- **插件同步**：按需同步社区插件、插件数据及启用状态，减少逐台配置。
- **外观同步**：同步主题、样式片段和选定的外观偏好。
- **使用习惯**：同步编辑偏好、快捷键与书签，让常用操作保持一致。
- **单独选择**：可排除具体项目，为不同设备保留各自需要的配置。
- **生效说明**：部分启用状态变更需重启 Obsidian；第三方插件仍受自身兼容性限制。

### 备份与恢复

- **版本历史**：查看并恢复笔记的历史版本，找回修改前的内容。
- **回收站**：在保留范围内找回已删除的内容，降低误删影响。
- **冲突处理**：提供冲突处理与恢复入口，帮助核对并保留需要的内容。
- **连接备份**：支持加密连接信息的导出与导入，方便恢复设备连接。
- **保留范围**：历史受服务策略和容量约束，永久清理后无法恢复；连接备份不是全库备份，重要笔记仍应另行备份。

### 自定义排序与置顶

- **分别排序**：文件与文件夹可分别设置主要、次要排序规则。
- **分层设置**：目录可继承上一级规则，也可单独调整。
- **笔记置顶**：将常用笔记置顶，减少反复查找。
- **本机生效**：排序作用于本机当前笔记库，关闭后恢复原有排序，不改变文件原始修改时间。

### 本地搜索

- **标题与正文**：通过独立搜索入口查找本机已有笔记。
- **条件筛选**：结合筛选条件缩小范围，更快定位需要的内容。
- **本机执行**：搜索在本地进行，尚未下载的云端内容不纳入结果。
- **加密范围**：加密且未解锁的内容不会作为普通明文搜索。

### 最近打开

- **快速回访**：集中查看最近打开的文件，返回刚才使用的笔记。
- **独立入口**：从最近列表直接打开文件，减少逐层查找。
- **本机记录**：最近列表在当前设备维护，方便延续本机的阅读和编辑。
- **自由开关**：可在设置中关闭最近功能，关闭后停止记录最近打开的文件。

## 安装与更新

- 官方社区入口：[Wujie Sync](https://community.obsidian.md/plugins/wujie-sync)。点击 **Add to Obsidian** 进入客户端安装页。审核通过后的客户端搜索收录可能存在延迟。
- 已通过 BRAT 安装的用户：仓库地址为 `adventurer2008/obsidian-smart-sync-release-cn`，可继续使用 BRAT 更新。
- 手动安装：从[对应版本的 Release](https://github.com/adventurer2008/obsidian-smart-sync-release-cn/releases)下载同一版本的 `main.js`、`manifest.json` 和 `styles.css`，校验 `SHA256SUMS.txt`。不要把 GitHub 的源码压缩包当作安装包。

本仓库只提供国内版。访问 GitHub 是从 GitHub 或 BRAT 下载、更新的前提。

## 从 0.1.72（smart-sync）迁移

0.1.73 起，国内插件 ID 改为 `wujie-sync`，Obsidian 会将它识别为独立插件，不能直接按原 ID 自动升级。

1. 先备份笔记库和插件设置；在旧插件中导出加密连接备份，保管好备份密码。
2. 停用旧 `smart-sync` 插件，不要退出账号或撤销设备授权。
3. 若使用 BRAT，移除旧仓库条目后重新添加当前国内发行仓库，启用新插件。
4. 导入加密连接备份，核对账号、笔记库、同步方向、排除项和附件偏好后再恢复同步。也可登录同一国内账号，使用原加密口令选择已有笔记库，不要新建重复库。

连接导入只迁移连接凭据，不代表全部偏好或同步检查点已迁移。已有云端数据和本地笔记保持原位，确认同步正常前保留停用的旧插件目录，不要同时启用两个同步插件，也不要把明文凭据复制进 `data.json`。0.1.72 的 tag 和附件保留。
